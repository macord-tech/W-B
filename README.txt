Preflight Briefing - offline iPad app

Upload everything in this folder to its own folder in your GitHub Pages repository,
for example  https://<your-name>.github.io/preflight-briefing/

On the iPad:
1. Open the address in Safari once while online.
2. Share > Add to Home Screen. The clipboard-and-airplanes icon is used.
3. Open it once from the home screen while online; after that it works offline.

When you upload a new version, change VERSION at the top of sw.js so the iPad picks it up.
Then add the address to Pilot Tools with "Add a tool".
